> # FanSHIM PWM Add-on for Home Assistant
> 
> This simple add-on for Home Assistant controls the Pimoroni FanSHIM on a Raspberry Pi 4 using PWM fan control.

## Features
- Progressive PWM fan control based on CPU temperature
- Runs automatically on HA boot
- Fully configurable via options in HA UI

## Installation
It is meant to be used on HA OS installed on a Raspberry Pi 4.

Add this repository URL in **Supervisor → Add-on Store → Repositories**, install and enjoy.
